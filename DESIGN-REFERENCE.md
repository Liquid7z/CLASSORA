# CLASSORA UI Reference

The included `DESIGN-REFERENCE.png` is the visual direction for the redesigned v0.4 interface.

## Roles
- Student: Dashboard, Notices, Events, Study Materials, Assignments, Academic Information, Search, Profile
- Teacher: Dashboard, My Subjects, Study Materials, Assignments, Notices, Events, Students, Academic Information, Search, Profile
- Admin: Dashboard, Institution, Users, Academic, Study Materials, Assignments, Notices, Events, Reports, Search, Settings

## Visual system
- Dark navy application shell
- Indigo/violet accent
- Glass-style cards
- Compact sidebar navigation
- Responsive mobile bottom navigation
- Search-first header
- Data-dense but spacious dashboards

This build keeps the existing local SQLite authentication, notes storage, and role-based routes while replacing the main UI with this design direction.
